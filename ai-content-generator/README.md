# AI Content Generator

A prompt-driven interface for generating content in different types and writing styles.

## Research
1. **What the UI pattern is:** a prompt box where the user describes what they need, picks a content type and style, and gets a generated draft.
2. **Where it is used:** writing assistants, marketing tools, email clients and CMS editors.
3. **Why it is relevant:** "describe it, then refine it" is now a standard interaction in AI products.
4. **Patterns observed:** prompt bar, type and style chips, streamed output, copy and regenerate, quick refine options, draft history.
5. **What this implementation adds:** one-click refine options, a restorable history, a floating-words 3D background and a custom cursor. Generation is simulated in JavaScript, so no API key is needed.

## Features
- Content types: Blog, Email, Caption
- Writing styles: Formal, Friendly, Playful
- Typing effect, Copy, Regenerate, Refine, Recent drafts

## Technologies
HTML, CSS, JavaScript

## Run
Open `index.html` in a browser.
